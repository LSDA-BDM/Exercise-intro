### Steps for solving exercises and assignments

1. Once you have a fork of the repository (a copy repository) you can open a *codespace* by pressing the button **<> Code**, then click on **Codespaces**, then **Create codespace on main**.
2. To practice updating the repository, navigate to the README.md file provided in the repository and make a small change (for example add some text).   
3. Commit and push the changes. For this, navigate to *Source Control* which will show you which files have changes. Choose the file you would like to commit and click the + button next to the filename; add a descriptive commit message and click *Commit*. You will then see the changes are staged to commit. Press *Sync Changes* which will push your updates to the repository. After this you and the teachers in the course should be able to see the changes you made in your code.
4. Now you can start working on the exercise. Navigate to `pandas_exercises.ipynb`. The dependencies needed to run the project will be installed in a local environment. For this exercise we only need the `pandas` library.
5. The first task is to import pandas `import pandas as pd`. Add the code and click run.
6. At the top of the notebook, under *Select Kernel* you can click *Install/Enable suggested extentions Python + Jupyter*
7. When you are prompted again to select a kernel choose Python Environments.
8. Then select the recommended python environment.
9. Now the import should work and you can continue with the rest of the exercise.
